# 中文译文质量规范

配合 `letter-zh-fidelity` 规则。目标语气：清楚、冷静、可读，接近仔细人工译文，而不是机翻腔。

## 忠实

- 语义与英文一一对应；不为「好读」删表、删注、删附录。
- 数字、年份、百分比、专有名词与源稿一致（若本年信修订了往年道指等数字，以**本年信表格**为准，可在导读旁注说明口径变化）。
- `.annotate` / `.say-plain` / 导读不得写进 `.original-body` 冒充原文。

## 语言

**要做**

- 完整中文句；典故与人名译出并括号保留英文必要时：彼得·米努伊特（Peter Minuit）、第五修正案、国税局。
- 固定译法优先与近年页一致：道指、有限合伙人、普通合伙人、分成、复利、清算所得、交割、税务裁定。
- 类别名可保留 Generals / Workouts / Controls，标题用中文括注：`「Generals——相对低估」`。
- 俏皮话保留锋芒，勿改成说教（曼哈顿印第安人、停车计时器、更大傻瓜理论等）。

**不要做**

- 中英夹生：`good year（好年）`、`The Ground Rules` 单独甩出而不译「基本规则」。
- 段中残留英文虚词：`substantially`、`nevertheless`、`largely`、`closing`、`payout`、`ruling`…
- 假朋友：workout 的 payout ≠「套利所得」→ 用「清算所得 / 派息估计」；`early next week` ≠「下月初」。
- 把 OCR/源稿笔误（如 world-be → would-be）译成胡话；按明显原意译，不必在正文解释校对。

## 结构

`.panel-zh` 建议顺序：

1. `.original-meta`（公司、地址、写信日期、忠实译自原文）
2. `.term-tip`：以哪封年终信为准；同年其他信一笔带过
3. 按英文信 `h2` 级标题逐节翻译（表现、投资公司、复利、运作方式、杂项、附录…）
4. 落款：诚挚的 / 沃伦·E·巴菲特

表格：表头中文化（年份 / 道指 / 合伙 / 有限合伙人）；基金名可保留英文简称。

## 易读版 vs 忠实译文

| | 易读（`.panel-easy`） | 折叠译文（`source-drawer`） |
|--|------|----------|
| 身份 | 主阅读：信息完整、更好读 | 核对措辞用的忠实译文 |
| 可删信息 | **否**（节、表、数字、杂项都要有） | 否 |
| 可改句式 | 是（短段、白话、层次） | 否（须对应英文） |
| 可加评价框架 | 是（`.say-plain`） | 否 |
| 数字 / 表 | 与译文 / 英文源一致 | 与英文源一致 |

Legacy 导读（`panel-guide`）可摘要；**1964+ 易读版不可摘要掉信息**。

## 自检提问

1. 若只读易读、不打开译文，能否掌握信里全部实质信息与表格？
2. 对照英文目录/小标题，易读与译文是否每一节都有对应？
3. 朗读两三段译文：是否像人话，还是词序英语、用词翻译腔？
